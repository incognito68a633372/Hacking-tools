# Security Toolkit (All-in-One Hacking Suite)

A comprehensive, modular collection of security and offensive tools written in Python. This repository consolidates various network analysis, scanning, and penetration testing utilities into a single, automated framework.

## ⚠️ Disclaimer
**Educational Use Only.** This toolkit is intended for educational purposes and authorized penetration testing only. The author takes no responsibility for any misuse or illegal activities conducted with this software. Always ensure you have explicit permission before testing any target.

## Features
This suite includes a wide range of modules for security research, including:

*   **Network Recon:** Advanced Port Scanning and IP Analysis.
*   **Stress Testing:** Layer 7 and volumetric DDoS simulation modules.
*   **Payload Generation:** Integration with MSFVenom for automated payload creation.
*   **Web Security:** Phishing kit management and vulnerability scanning.
*   **Credential Attacks:** Hash cracking and brute-force utilities.
*   **Wireless/Bluetooth:** Specialized modules for Wi-Fi (WPA/WPA2) and IoT interaction.
*   **Social Engineering:** SMS bombing and spoofing capabilities.
